# Calibration Service 版本日志

当前版本：`1.4.1`

## 1.4.1 - 2026-08-11

### 修复

- 新增只读 `GET /api/v1/health`，明确返回 `service_version` 和当前任务状态，供客户端统一做版本校验。

## 1.4.0 - 2026-08-11

### 变更

- 所有进入二次确认的先验和标定响应增加 `data.result`，头部 ChArUco 与手部三球先验直接返回待确认 JSON 的完整详细结果。
- 手眼在手上与头部眼在手外标定的待确认响应增加完整矩阵、平移、RPY、样本数及求解指标；正式结果仍只在确认后替换。

## 1.3.0 - 2026-08-11

### 变更

- 头部 ChArUco 先验、手部三球先验及其它待确认结果最多保留 30 秒；超时未确认或取消时自动丢弃临时结果，不替换 RecordReplay 正式文件。
- 待确认响应和服务状态增加 `expires_at`，供客户端展示确认截止时间。

## 1.2.0 - 2026-08-10

### 新增

- 增加手眼 ChArUco 默认参数查询与 PATCH 更新接口；字典选项动态取自当前 OpenCV。
- 手眼在手上和头部眼在手外采样统一使用可配置的板参数。

## 1.1.1 - 2026-08-07

### 修复

- 收回手眼算法、先验记录算法和 CameraPipeline HTTP 协议 DTO；服务运行时不再导入仓库 `src/` 或 CameraPipeline Python 包。

## 1.1.0 - 2026-08-07

### 新增

- 计算结果先进入待确认缓存，新增取消接口和替换二次确认接口。
- 正式替换时保留旧文件，并按 `yymmdd_hhmmss` 后缀重命名，不直接删除。
