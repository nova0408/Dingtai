# CameraPipeline 版本日志

当前版本：`1.0.0`

## 版本号规则

版本号使用 `a.b.c`：

- `a`：重大重构或重大更新。
- `b`：功能调整，包括新增、删除或改变 API、协议能力及服务行为。
- `c`：缺陷修复和不改变功能边界的优化。

每次更新 API 或功能时，必须同步更新当前版本号，并在本文件顶部追加带日期的版本记录。同一批改动只升级一次，按影响最大的改动选择版本位。

## 1.0.0 - 2026-07-21

### 初始基线

- 提供统一的多相机查询、RGBD/彩色/深度订阅和稳定帧 API。
- 提供三球检测与 Charuco 检测服务能力。
- 公共客户端同时支持 Windows 开发机访问 Orin 和 Orin 本机服务调用。
- 服务功能版本从 `1.0.0` 开始维护；网络协议版本独立管理。
