# Opening Detection

> 暂时移除：本模块已从 CameraPipeline 运行时、RPC 协议和公共 client API 摘除，
> `__init__.py` 已删除。目录内源码仅作后续恢复参考，当前 Python 3.12 部署不会加载本模块。

## 单一职责

`opening_detection` 接收一帧 RGBD 和一个已经选定的托盘 mask，检测矩形开口、拟合局部三维平面并计算抓取位姿。它不检测托盘、不选择托盘索引、不访问相机，也不创建 RPC。

tray → opening 的业务组合位于 `camera_pipeline.service.application`。

## 模块结构

| 文件 | 职责 |
| --- | --- |
| `opening_pipeline.py` | 高对比域、矩形开口、局部区域 mask 和顶面法向计算 |
| `pose_pipeline.py` | 平面拟合、射线求交、抓取坐标系和时序平滑 |
| `engine.py` | RGBD 转点云、串联图像与几何算法、组装结果 |
| `service.py` | 纯计算执行器薄入口 |
| `types.py` | 内部开口、平面和抓取结果 |
| `protocol.py` | 请求、响应、位姿和 debug 协议 |

## 算法理论

### 二维开口

彩色图先转换到高对比灰度域并提取边缘。在托盘 mask 内扫描灰度阈值，形成候选连通域；候选通过面积、矩形度、暗区比例和边缘贴合度评分，最终使用旋转矩形表达中心和四角。

固化后的预处理、Canny 和区域生长参数集中在 `OpeningDetectionConfig`，由 `OpeningDetectionPipelineExecutorConfig` 显式传入。算法实现中不再保留开发期全局 `DEFAULT_*` 参数区。

### RGBD 点云

有效深度像素按针孔模型反投影：

```text
X = (u - cx) * Z / fx
Y = (v - cy) * Z / fy
Z = depth_mm
```

所有三维输出均位于相机坐标系，长度单位为 mm。

### 局部平面

开口附近点云过滤后计算协方差矩阵，最小特征值对应的特征向量作为平面法向量：

```text
n · x + d = 0
```

法向量朝向根据相机参考方向统一。

### 抓取位姿

开口中心像素射线与局部平面求交得到抓取点。开口长边两端分别与平面求交，形成抓取坐标系 X 轴；参考顶面法向形成 Y 轴；`Z = X × Y`，随后重新正交化。预抓取点沿 Z 轴偏移 80 mm。

位姿旋转矩阵列向量依次为 X、Y、Z。该模块输出矩阵协议，不在内部转换欧拉角。

### 时序平滑

抓取点使用历史中值和 EMA，轴向使用单位向量/旋转平滑，并对单帧最大平移与最大角变化做门控。稳定帧输入仍是上游前置条件，时序平滑不能代替画面稳定判断。

## 输入输出

输入包括：

- RGBD 帧及 `fx/fy/cx/cy`；
- 单个托盘 `uint8` mask；
- 请求号、目标托盘索引和 debug 开关。

输出 `TrayPoseInfo` 和可选 `DebugArtifacts`，包括开口中心/四角、抓取点、预抓取点、旋转矩阵、局部 mask 和叠加图。

关闭 debug 时不构造原图副本、mask 栈和叠加图，响应中的 `debug_artifacts` 为空元组。成功响应始终包含完整 `TrayPoseInfo`，无法计算抓取位姿时直接报告业务错误，不返回字段为 `None` 的半成品结果。

## 成功与失败语义

- 成功：返回完整 `TrayPoseInfo`，包含开口几何、抓取点、预抓取点和旋转矩阵。
- debug 关闭：`debug_artifacts=()`。
- mask 为空、有效深度不足、平面拟合失败或抓取位姿无法构造：抛出异常，由服务层转换为统一错误。
- opening 不使用“空成功结果”掩盖不可抓取状态。

## 调参建议

1. 先检查相机内参和深度单位，错误内参会系统性破坏三维结果。
2. 使用 tray mask 叠加图确认输入区域，再调开口灰度与边缘参数。
3. 对不同材质分别统计开口灰度、边缘强度和候选评分，不要只调单张图。
4. 局部点不足时先检查深度空洞和 ROI，而不是降低平面最小点数。
5. `top_normal_alpha` 越小越平滑但响应更慢。
6. `grasp_point_alpha`、`grasp_axis_alpha` 控制位置和方向响应速度。
7. 最大平移/角度阈值用于阻止异常跳变，应根据机械允许误差设置。
8. 软门控阈值应略高于静态噪声，而低于真实目标移动量。

## 局限性

- 假设目标开口近似矩形，异形或严重遮挡开口可能失败。
- 深度反光、黑色材质和边缘空洞会降低平面拟合质量。
- 协方差最小特征向量拟合不具备强离群点鲁棒性。
- 顶面 mask 计算有短超时，超时时会使用基础平面结果。
- 时序状态保存在执行器实例中，不适合交错处理多个独立相机序列。
- 抓取坐标系方向依赖当前参考轴约定，部署前必须用真实机器人坐标变换验证。
